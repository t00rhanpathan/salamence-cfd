# salamence-cfd

Salamence vs Mega Salamence aerodynamics: an open-source, laptop-scale CFD study for a preprint.

- `SPEC.md` is the plan; `CONTEXT.md` is the one-page brief every agent reads; `assumptions.yaml` holds every input number.
- Setup (Windows + WSL2 Ubuntu): `bash setup/install_wsl.sh`, then `bash setup/check_env.sh`.
- Start: open Claude Code in this folder inside WSL with `claude --model claude-fable-5-2` and ask it to run phase 1.
